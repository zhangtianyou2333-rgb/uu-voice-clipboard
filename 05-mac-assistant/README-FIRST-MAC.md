# Mac 接收助手 V1.0.3（参考）

用于被控 Mac 接收 Windows 经 UU 同步的带标记剪贴板；不进行语音识别，不能在 Windows 运行。

解压后打开 UU Mac Paste Assistant.app，在系统设置中按实际提示允许辅助功能权限。菜单默认选“应用菜单粘贴”，开启自动粘贴；目标输入应用保持前台。Windows 发送端启用“自动转发到接收助手”。先测短句，再测长句和换行，核对是否完整插入。

关闭旧助手后再更新，避免两份并存。菜单请求被接受不能独立证明正文已经插入。遇到目标/剪贴板变化就取消，不应无界抢焦点或重复输入。复制诊断会覆盖剪贴板。

源码构建：在本目录运行 zsh run-tests.sh，再运行 zsh build-mac-assistant.sh。脚本拒绝覆盖现有同版本产物。配套 Windows → Windows 改造教程位于源码包 docs/。
