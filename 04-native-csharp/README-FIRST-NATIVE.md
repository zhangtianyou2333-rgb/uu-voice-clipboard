# UU 语音中转 V1.12.0 · 会员预览版

完整解压后运行 Start-Native.vbs，WebView2Loader.dll 与 EXE 保持同目录；需要 WebView2 Runtime。

F12 打开/找回输入框，右 Alt 启停豆包；最终文字确认后自动完成或点“完成并转发”。F12 不停止录音。

托盘只保留：打开输入框、自动转发、复制诊断、关于、退出。关闭自动转发则只复制纯文本。启用时需要远端接收助手；现有 Mac 助手 V1.0.3 可作参考，Windows 接收助手仍需按教程实现。发送端没有远端粘贴回执。

旧托盘必须先退出；叉号只隐藏。首次运行沿用当前用户开机启动逻辑。复制诊断会覆盖剪贴板。

本版去掉了旧输入框切换、UU 多种模拟粘贴及驱动路径。本地构建不能证明真实语音和远端插入已通过。完整教程见配套源码包 docs/。
