# 双机验收清单

填写实测日期、A/B 系统版本、UU 版本、豆包版本、发送/接收版本。每项填写“通过 / 失败 / 未测”、实际结果和必要的无敏感截图。默认都是未测。

| 项目 | 通过标准 | 本次会员 Windows 双机结果 |
| --- | --- | --- |
| 普通文本同步 | A 复制，B 手动粘贴，全文一致 | 未测 |
| 后缀保留 | B 收到全部八个标记码位，普通文本不匹配 | 未测 |
| 本机语音 | 连续说 20 秒，不在约 1 秒时被中断 | 未测 |
| F12 / 右 Alt | F12 打开/找回，右 Alt 启停，F12 不停止录音 | 未测 |
| 未确认候选 | composition 活跃时不提前复制部分文字 | 未测 |
| 长语音 | 超过一屏持续显示，结束后逐字比较无缺失 | 未测 |
| 纯文本模式 | 关闭自动转发，没有标记、没有自动插入 | 未测 |
| 普通复制 | 在 B 复制普通文字，不触发接收助手粘贴 | 未测 |
| 自身清理与回流 | 去标记的本地写入及 UU 回流不重复粘贴 | 未测 |
| 连续 10 次 | 每次只插入一次，无上一次旧内容 | 未测 |
| 重复说相同句子 | 两次独立会话各自插入一次 | 未测 |
| 焦点变化 | 等待中用户切到其他应用后取消，文字不误插入 | 未测 |
| 剪贴板覆盖 | 等待中复制其他文字，旧请求取消，不覆盖新内容 | 未测 |
| 权限与密码框 | 权限不匹配、密码框或目标不明时回退手动 | 未测 |
| 自动模式关闭 | 无自动输入，无隐式按 Enter | 未测 |
| 接收端关闭 | A 只报本地交付，不能报 B 已输入 | 未测 |
| 重启接收端 | 不处理启动前旧剪贴板 | 未测 |
| 断开/重连 UU | 无意外旧输入；V1 不保证跨重连恰好一次 | 未测 |
| 关闭/取消 | 叉号后无迟到回调恢复旧框或再次传输 | 未测 |
| 界面缩放 | 100%/125%/150% 下菜单、按钮、输入区可用 | 未测 |
| 日志 | 没有正文/窗口标题；只含阶段、计数、耗时 | 未测 |

判断自动插入是否成功要看 B 的真实输入框。仅有“已交付”“发送成功”“事件返回数量”或包生成，都只能证明相应局部步骤。
