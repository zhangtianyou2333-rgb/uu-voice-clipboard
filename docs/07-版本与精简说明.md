# 版本与精简说明

整理日期：2026-10-24。基线为原 Windows V1.11.4 与 Mac 助手 V1.0.3。此次 Windows 改为 V1.12.0 会员预览版，原始工程和原安装包另行保留。

## 已移除

- 托盘的扫描码 SendInput / 窗口消息 / 虚拟键 SendInput / 驱动通道选择。
- 驱动安装、驱动诊断及命令行安装入口；InputInterceptor NuGet 依赖与桥接源码。
- Raw 右 Alt 实验的参数、注册、回调与源码；右 Alt 继续交给豆包。
- 旧 TextBox / RichEdit 输入框、原生视口和切换菜单；分享版固定 WebView2，不读取旧回退偏好。
- 发送端恢复 UU 远程画面并注入 Ctrl+V 的派发逻辑与注入方法。
- 重复的“自动粘贴到 UU”和“Mac 助手自动粘贴”开关，合成“自动转发到接收助手”。

原生 composition 共用接口和策略测试仍被 WebView2 输入宿主使用；相关支持代码按依赖保留，不能仅看类名就当成无用文件删除。

## 保留与调整

保留输入宿主、F12 完成/找回、右 Alt 透传、composition 完成保护、关闭取消、长候选视口策略、原 UI 与 Mac 兼容后缀。保留纯文本复制和不含正文的诊断。

菜单双击/打开改为复用 F12 的会话判断，找回面板时不清空当前文字。用户按“完成并转发”后仅报告本地同步剪贴板写入，接收端是否粘贴保持未确认。原代码结果字段 PasteSent 改为 ReceiverHandoff，避免把交付当作远端成功。

历史现有输入恢复的现场反馈不能覆盖本次精简改动。此版需独立做 Windows 持续录音、长语音、菜单点击/缩放与 Mac 插入验收。

## 本地验证记录

见同目录 `08-本地验证记录.md`。运行包应与本目录源码一致；查看外层包的 `SHA256SUMS.txt` 验证完整性。

Windows → Windows 自动接收未实现。修改说明和 AI 提示词是后续开发任务，不是已完成的功能。

旧 Mac 参考程序含本机源码/对象文件路径，现以独立 PublicClean ZIP 替换；清理调试映射后重新做匿名签名。Swift 功能源码与程序文本段保持，版本仍 V1.0.3。构建脚本补充路径映射及签名前 strip。详见公开前检查报告；先前的会员整包不作为公开上传候选。
