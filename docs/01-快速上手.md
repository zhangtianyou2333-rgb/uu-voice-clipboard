# 快速上手

## 两台电脑各自做什么

Windows A 是正在说话的电脑，安装豆包输入法，运行本项目发送端，并通过 UU 控制另一台电脑 B。B 是文字最终出现的电脑，运行接收助手。两端都必须开启 UU 文本剪贴板同步。

如果目标是 Windows B，本包还没有可直接运行的 Windows 接收端：先做下面的手动同步验证，再按改造教程开发。不要把 Mac `.app` 放到 Windows 上运行，也不要在 A、B 同时运行发送端并期待自动完成接收。

## 先验证普通文字

1. 连接 UU，先在 A 复制一句无敏感内容的文字。
2. 在 B 打开普通记事本/文本编辑器，使用实体快捷键粘贴。
3. 确认内容、换行、中文和 emoji 完整。此步失败先处理 UU 剪贴板同步。

## Windows A 发送端

1. 从旧托盘选择退出，完整解压会员预览版 ZIP 到新目录。
2. EXE 与 WebView2Loader.dll 保持在同一目录，双击 Start-Native.vbs。
3. 先取消勾选“自动转发到接收助手”，测试纯文本复制。
4. F12 打开输入框，用右 Alt 启动豆包，说完后右 Alt 停止并等待文字确认。
5. 自动收尾或按“完成并复制”，在 A 的记事本以及 B 的记事本手动粘贴，比较全文。
6. 只有接收助手就绪后，再勾选“自动转发到接收助手”。发送端会写入带标记文字；接收端必须去掉标记再粘贴。

首次运行沿用旧工程的当前用户开机启动设置逻辑。面板的叉号仅隐藏/取消当前会话；彻底关闭程序要从托盘选择退出。不要让新旧发送端同时运行。

输入框加载失败时检查 WebView2 Runtime，或复制诊断；精简版不再提供旧 TextBox / RichEdit 切换。诊断复制会覆盖剪贴板，测试文字先另行保留。

## 现有 Mac B 参考流程

解压 Mac V1.0.3 参考包，打开 UU Mac Paste Assistant.app，按系统提示授予辅助功能权限。菜单默认使用“应用菜单粘贴”。让实际输入应用保持前台，在 A 启用自动转发并做一次短句测试，再测长语音。用户手动切换应用后不应在其他应用意外插入。

Mac 参考包是原版本，签名和权限处理以实际系统提示为准。原包内部说明有历史排查内容；新会员以本指南和本次验收清单为入口。
